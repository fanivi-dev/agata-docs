**Explore** ranks public studios you can already resolve. It is not a new
directory, search engine, or follow graph.

## Route

```txt
/explore
```

**Explore** is in the account-wide sidebar alongside Studios, Following,
Connections, and Inbox.

## What it ranks

There is no recommendations API. The page composes existing reads:

- Connection usernames and names, resolved with `GET /p/{handle}`
- Public studios you belong to but do not own

Private studios stay 404, same as `/@handle`. Owned studios stay on
[Studios](/getting-started/first-studio). Exact handle lookup lives here
too: type `@handle` or a name that slugs to one. It uses the same
`GET /api/p/:handle` path as `/@handle`.

| Signal | Source |
| --- | --- |
| Followers | `followerCount` on the public studio |
| Subscribers | `subscriberCount` on the public studio |
| Starting price | Lowest active `membershipPlans` amount (EUR, month or year) |
| Public activity | Counts from public recipes, collections, library items, goals, meal days, notes, routines, boards, and habits |
| Kind | Person or organization |
| Public presence | Bio and image on the public studio |
| Follow / member | `isFollowing` and `viewerIsMember` |

Sort defaults to that mix. You can switch to followers, public activity, or name.

`GET /api/p/:handle` also returns `isSubscribed`, `viewerCanMessage`, and
active `membershipPlans`. Join and Message live on the public studio,
not on Explore.

## Capabilities

| Action | Detail |
| --- | --- |
| Filter | All / People / Organizations / Not following |
| Search | Name, handle, bio, or exact `@handle` lookup |
| Follow | Same `POST` / `DELETE /p/{handle}/follow` as the public studio page |
| Open | `/@handle` |

Active scope filters also apply to exact handle matches. Empty filtered results
provide **Clear filters** to reset the search and scope. An empty recommendation
list links to Connections.

## Following

`/following` lists followed and subscribed Studios. Search by name or handle,
then narrow to Followed or Subscribed. Empty search results offer a filter
reset; an empty account list links to Explore.

## AI relevance sort

With a non-empty search query, **Sort by relevance with AI** reranks the current visible public candidate set (at most 24 handles). Order is view-local and keyed by query, scope, sort, and candidates; stale responses are discarded. Undo restores the prior sort. No server-side ranking model is stored.

## Stack

- UI: `features/platform/domains/explore/`
- BFF: `studiosQueries.listRecommendedPublicStudios` plus
  `studiosQueries.getPublicStudio` for handle lookup
- Nav: `shared/constants/platform-area-catalog.ts`

## It is not

- A substitute for Connections (people you invite as members).
- A substitute for Studios (workspaces you run or belong to).
- A substitute for [Memberships](/platform/memberships) or Follow.
- A new ranking product or stored recommendation model.
