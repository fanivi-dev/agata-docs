## Team enablement

| App | Team default (indicative) |
| --- | --- |
| Notebook / tasks / projects / tags / library | On |
| Finance / health / nutrition | Off until admin opt-in |
| Goals / pomodoro | Depends on studio settings |
| Tasks | **Always** on |
| Agent | **Always** on |

## How to switch apps

- Shell launcher  
- Command palette (⌘K)  
- Deep links in the same `studioId`  

Visually, each app can tint primary/accents: [App themes](/design-system/app-themes).
