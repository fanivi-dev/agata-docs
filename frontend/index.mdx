## Current public URL model

| Layer | Shape |
| --- | --- |
| Browser (product) | `/orgs/:orgHandle/:handle/...` |
| Internal App Router tree | `app/(authenticated)/studios/[studioId]/...` |
| Go / OpenAPI HTTP | `/api/.../profiles/{studioId}/...` |

Earlier drafts that taught `/profiles/[studioId]/...` as the public app URL, or
bare `/studios` / `/today` as top-level protected prefixes, are withdrawn.
Legacy `/studios` still 308-rewrites into the org directory for bookmarks.

For stable product and UI work:

- **[General](/getting-started/overview)** — what the product does
- **[Local development](/getting-started/local-development)** — clone → migrate → API → app
- **[Design system](/design-system)** — components and tokens
- **[API](/api)** — contract with Go

Verification: `bun run lint:architecture` and `bun --filter app type-check`.
