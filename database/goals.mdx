## `goal_images`

Same blob pattern as `activity_images`: store, pathname, etag, position, soft delete. One active image per goal (an attach replaces the previous one).

Goals are unlimited for customers. Private abuse safeguards may return `CAPACITY_GUARD_REACHED`.

## `vision_boards`

Source: `000058_vision_boards.up.sql`. Visual collages in the Goals app.

| Column | Notes |
| --- | --- |
| `profile_id` / `user_id` | Author (shared in the profile) |
| `title` / `intention` | Name and intention |
| `status` | `active` \| `archived` |
| `is_favorite` | Personal favorite |
| `background_kind` | `color` \| `image` |
| `background_value` | Preset (`paper`, `linen`, …) or URL |
| `canvas_width` / `canvas_height` | Virtual canvas (default 1600×1000) |
| soft delete | |

Index by profile + `updated_at`.

## `vision_board_goal_links`

Board ↔ goal link (`PRIMARY KEY (board_id, goal_id)`). `ON DELETE CASCADE` on both ends.

Domain limits (not plan limits): 50 boards per profile, 80 items per board.
