title: "Places"
description: "Profile-scoped geographic places (name + coordinates)."
---

Source: `000074_places.up.sql`. Domain FKs: `000075_domain_places.up.sql`.

Places are a shared lookup, not a Travel app. Product rows (library items, reminders, sessions, and later FKs) store a nullable `place_id`. Nutrition pantry `location` is still a storage label, not this table.

## `places`

| Column | Notes |
| --- | --- |
| `profile_id` / `created_by` | Profile scoped. Soft delete via `deleted_at`. |
| `name` | Required label. |
| `address` | Optional free-text address. |
| `lat` / `lng` | `DOUBLE PRECISION`. Checks: lat −90…90, lng −180…180. |
| `provider` | `manual` or leftover `url` from the retired Maps paste field. |
| `provider_id` | Optional external id. |
| `source_url` | Unused leftover column. |

No PostGIS. Health sessions may store `route_geojson` on the session row.

Nullable `place_id` FKs (see `000075_domain_places.up.sql`): `library_items`, `reminders`, `health_exercise_routines`, `health_exercise_sessions`, `nutrition_shopping_collections`, `nutrition_meal_logs`, `tasks`, `week_plan_items`, `finance_transactions`, `finance_recurring_rules`, `goals`, `goal_milestones`, `activities`.

API: `/places/profiles/{profileId}/places`.
