Primary source: `000005_domains.up.sql` (large file).

Migration `000096_ai_notebook_today.up.sql` adds revisioned symmetric
`note_relations` and the personal, date-scoped `daily_focus_sets` /
`daily_focus_items` storage used by Notebook and Today AI actions. An empty
focus set is meaningful and suppresses the derived due-today fallback until the
user resets it.
