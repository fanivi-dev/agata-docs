## `"user"`

| Column | Type | Notes |
| --- | --- | --- |
| `id` | TEXT PK | Auth id |
| `name` | TEXT NOT NULL | |
| `email` | TEXT NOT NULL | Unique |
| `emailVerified` | BOOLEAN | Default false |
| `image` | TEXT | |
| `stripeCustomerId` | TEXT | Billing plugin |
| `termsAcceptedAt` | TIMESTAMPTZ | Acceptance date on accounts created since the current legal version |
| `termsVersion` | TEXT | Accepted Terms version |
| `privacyNoticeVersion` | TEXT | Version of the privacy notice presented and accepted |
| `createdAt` / `updatedAt` | TIMESTAMPTZ | |

Legal fields are assigned server-side when creating an account and are not exposed
as client input fields. Accounts from before the migration stay `NULL`: no
retroactive acceptance is recorded that did not happen.

## `account`

Provider accounts (OAuth / credentials):

| Column | Notes |
| --- | --- |
| `issuer` | Required. Credential accounts use `local:credential`. OAuth uses the provider issuer (Google: `https://accounts.google.com`) or `local:oauth:<providerId>`. Unique with `accountId`. |
| `accountId` / `providerId` | Provider identity. For email/password, `accountId` equals `"user".id`. |
| `userId` | Owner |
| `accessToken` / `refreshToken` / `idToken` | Secrets |
| `accessTokenExpiresAt` / `refreshTokenExpiresAt` | |
| `scope` / `password` | |
| timestamps | |

## Usage rules

- Do not mutate these tables from product-domain GORM.
- Login/session = Better Auth API (`/api/auth/*` in Next).
- The product uses `users.id` after the identity mirror.
