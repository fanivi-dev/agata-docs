All paths are relative to **`/api`**. The canonical registry is in `handler.go`.

## Platform

| Prefix | Auth | Description |
| --- | --- | --- |
| `/health`, `/health/ready` | Public | Liveness / readiness |
| `/p/:handle…` | Public | Public profile and shareable rows (browser `/@handle`) |
| `/users/me…` | User | User, preferences, connections, invitations |
| `/profiles…` | User | Profile CRUD, members, audit, usage, and Agent credits |
| `/feedback/profiles/:id` | Profile | Submit feedback (reads live at `/internal/feedback*`) |
| `/blob/profiles/:id…` | Profile | Attach blob metadata |
| `/tags/profiles/:id…` | Profile | Tags and links |
| `/projects…` (see OpenAPI) | Profile | Projects |

→ [Platform](/api/reference/platform)

## Internal

| Prefix | Auth | Description |
| --- | --- | --- |
| `/webhooks/metronome` | HMAC signature | Idempotent Metronome event inbox |
| `/qstash/*` | `Upstash-Signature` | Idempotent dispatch and QStash failure recovery |
| `/internal/qstash/recover` | `CRON_SECRET` | Hourly safety net for notifications and Metronome |
| `/internal/billing/stripe/sync` | `CRON_SECRET` | Projection of plan, period, interval, and extras |
| `/internal/billing/metronome/dispatch` | `CRON_SECRET` | Manual dispatch of the usage and contracts outbox |
| `/internal/billing/metronome/reconcile` | `CRON_SECRET` | Manual reconciliation against the canonical ledger |

Internal operations are not product API. Their operational contracts are
in the OpenAPI reference and the canonical registry remains in `handler.go`.

## How to use this map

1. Find the prefix.
2. Open the domain guide or the **OpenAPI reference** in the sidebar (autogenerated endpoints).
3. Copy the example from the guide or the playground.
