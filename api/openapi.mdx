## Canonical spec (product monorepo)

```txt
apps/api/docs/openapi.yaml
```

- OpenAPI **3.0.3**
- Base paths under `/api`
- Tags by domain (Users, Tasks, Finance, …)
- Security schemes: session bearer (+ cron bearer on internal routes)

## Copy on the docs site

Docs7 only packages the **`apps/docs`** directory. That is why there is a copy:

```txt
apps/docs/openapi/agata-v1.yaml
```

The sidebar includes the **OpenAPI Reference** group, generated automatically from that file (pages per operation + playground).

## How to keep them in sync

When you change routes or schemas in Go:

1. Update `apps/api/docs/openapi.yaml` (backend source of truth).
2. Copy to docs:

```bash
cp apps/api/docs/openapi.yaml apps/docs/openapi/agata-v1.yaml
```

3. Commit both files in the same PR.
4. Merge to `main` → Docs7 redeploy.

<Tip>
  Ideally a CI script `docs:sync-openapi` does the `cp` and fails if they differ. It can be added later.
</Tip>
