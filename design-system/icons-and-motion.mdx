## Icons

```tsx
import { Icon } from '@agata/ui/components/icon';
import { CheckListIcon } from '@hugeicons/core-free-icons';

<Icon icon={CheckListIcon} size="sm" />
```

The adapter converts Hugeicons data into Astryx's SVG component contract.
Astryx owns size, semantic color, and accessibility. Registries use the
`IconComponent` type exported by the adapter.

Use supported `size` and `color` props, such as `size="sm"` and
`color="secondary"`. Use `xstyle` only for layout the component cannot express.
For runtime colors on an owned native container, use `color="inherit"`.
Icon-only actions use `IconButton` with a meaningful accessible `label`.
Do not introduce another web icon library.

## Motion tokens

Use the official `durationVars` and `easeVars` from
`@astryxdesign/core/theme/tokens.stylex`:

| Family | Tokens |
| --- | --- |
| Fast | `--duration-fast-min`, `--duration-fast`, `--duration-fast-max` |
| Medium | `--duration-medium-min`, `--duration-medium`, `--duration-medium-max` |
| Slow | `--duration-slow-min`, `--duration-slow`, `--duration-slow-max` |
| Easing | `--ease-standard` |

Astryx owns their values. Do not restore local `--dur-*` or easing scales.
Respect reduced motion, prefer opacity/transform, and use animation to explain
state or spatial continuity. Integration keyframes live in
`packages/ui/styles/keyframe-animations.css`; StyleX-owned animation stays with
its component.

## Route transitions

The installed React/Next.js stack uses `ViewTransition` and `transitionTypes`.
The shared boundary is
`apps/app/shared/components/profile-route-transition.tsx`; participating product
segments mount it in `template.tsx` inside their persistent layout.

| Navigation type | Use | Movement |
| --- | --- | --- |
| `nav-forward` | List or summary → detail | Content advances horizontally |
| `nav-back` | Detail → parent, breadcrumb, or return after delete | Reverse direction |
| `nav-peer` | Apps, tabs, or same-level destinations | Crossfade |

Use the constants in `shared/lib/navigation/view-transition-types.ts` rather
than inventing strings. Links and router navigation declare `transitionTypes`.
Untyped navigation, browser history, refreshes, and Suspense reveals remain
instant.

Keep the shell outside the animated boundary. Do not add a remounting boundary
to Agent's persistent chat layout. Route motion uses official fast/medium duration tokens and only
opacity/transform. Its CSS disables transition timing for reduced motion. Do not assume a shared-element morph when the destination cannot resolve
in the same commit.
