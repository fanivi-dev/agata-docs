## Recipes

| Tool | R/W | Endpoint |
| --- | --- | --- |
| `list_recipes` | R | `GET .../recipes` |
| `get_recipe` | R | `GET .../recipes/{recipeId}` |
| `create_recipe` | W | `POST .../recipes` |
| `update_recipe` | W | `PATCH .../recipes/{recipeId}` + `POST` of ingredients / steps / tools |

A complete recipe is always saved in two phases within the same turn:

1. `create_recipe` creates the header (name, description, and servings) and returns the ID.
2. `update_recipe` takes that ID as `recipeId` and adds, in a single call, every ingredient, ordered step, and tool.

The `update_recipe` arrays are additive: they keep existing rows. When creating a new recipe, send the full list after `create_recipe`; Eve must not stop after creating the header or send the user to manual editing.

</Note>
