## Progress modes

A goal's progress is computed in three ways, according to its `progressMode`:

| Mode | How it advances |
| --- | --- |
| `manual` | The percentage is set by hand with `manualProgressPercent`. |
| `milestones` | Derived from completed milestones. |
| `linked` | Derived from linked entities (tasks, activities…). |

<Warning>
`manualProgressPercent` **only takes effect in `manual` mode**. The `update_goal` description says so, and `get_goal` is how to check the mode before trying to set a percentage.
</Warning>

On goals in `milestones` mode, what moves progress is `update_goal_milestone` with `completed: true` — not `update_goal`.

To link work: `list_goal_linkable_entities` then `link_entity_to_goal` (`linkType`: `task` | `activity` | `finance_goal`).

## Risk

`list_goals` and `get_goal` return `isAtRisk`, which the API computes by comparing progress with the target date. It requires a `todayDateKey`, which the handler derives from the session timezone instead of asking the model.

`get_goal` also includes milestones with their status, trimmed to `id`, `title`, and `completed`.
